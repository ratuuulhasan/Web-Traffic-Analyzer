📘 How to Track Events (For Your Website)

Add the tracking script first (already shown in your website dashboard). Then use:

1. Manual Tracking
// Button click
<button onclick="trackEvent('signup_click', {button: 'header_cta'})">Sign Up</button>

// Purchase
trackEvent('purchase', {amount: 99, currency: 'USD', product: 'Pro Plan'});

// Video play
trackEvent('video_play', {video_id: 'abc123', duration: 120});
2. Auto-tracking with data attribute
<button data-ta-event="cta_click">Click Me</button>
<a href="/pricing" data-ta-event="view_pricing">See Pricing</a>
3. What's tracked automatically
  • ✅ Form submissions → form_submit event
  • ✅ Outbound link clicks → outbound_click event
  • ✅ Any element with data-ta-event attribute
