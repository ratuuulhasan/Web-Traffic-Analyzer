📘 How to Track Events

After installing the tracking script, use these methods:

Manual Tracking
// Button click
<button onclick="trackEvent('signup_click', {button: 'header_cta'})">Sign Up</button>

// Purchase
trackEvent('purchase', {amount: 99, currency: 'USD'});

// Video play
trackEvent('video_play', {video_id: 'abc123'});
Auto-tracking
<button data-ta-event="cta_click">Click Me</button>
What's tracked automatically
  • ✅ Form submissions → form_submit
  • ✅ Outbound links → outbound_click
  • ✅ Elements with data-ta-event
